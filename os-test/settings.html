cross-os

One-time GitHub Setup

This tool uses your GitHub repository and cloud Actions runners to capture screenshots of your site across Windows, macOS, and Linux for free. Your token is stored locally in your browser and never leaves your machine. If you already connected your GitHub Dashboard, leave the token empty and it will be reused automatically — you only need to fill in the owner and repo name of the target repo holding the test workflow.

Step 1: Create a Personal Access Token

Choose whichever token type you prefer:

Option A: Classic Token (Fastest — 1 Click)

Creates a classic token with the repo scope pre-selected.

Create Pre-filled Classic Token ↗

Option B: Fine-grained Token (Scoped)

Go to github.com/settings/tokens?type=beta, scope to your repo, and grant:

  • Actions: Read and write
  • Contents: Read and write

Step 3: How to Test Any UI

  1. Prepare the target repo: the repo you test from must contain the Cross-OS workflow. Copy the files from the extension's os-test/workflow-assets/ folder (screenshot-test.yml under .github/workflows/, plus scripts/ and package.json) and create an empty results branch.
  2. Open the site you want to test in Google Chrome (HTTP or HTTPS), then click the Cross-OS Test button in the Developer Companion canvas toolbar.
  3. Configure capture mode: Select Full page or Visible area, and check the target browsers (Chrome, Firefox, Safari/WebKit).
  4. Click "Run test": Runners spin up on Windows, macOS, and Linux in the cloud and stream results back live.
  5. Inspect & Compare:
    • Click Expand all to view all 9 screenshots side-by-side.
    • Click any screenshot to open the full-resolution Lightbox zoom modal.
