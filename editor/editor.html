How to Connect to Your AI Agent in Backend
Checking local backend connection (port 5959)...

The Big Picture: How This Works

This extension is your visual cockpit (drawing UI designs and collecting browser errors). The backend server is a lightweight script on your machine that gives your AI agent (Claude Code, Cursor, Antigravity, etc.) instant access to those sketches and logs via the standard MCP (Model Context Protocol).

1

Start the Local Backend Server

Your agent connects to the local server running on port 5959. Start it with one of these options:

Option A: One-click installer (Easiest)

In the project folder, simply double-click:

  • Mac / Linux: Install-Mac-Linux.command
  • Windows: Install-Windows.bat
Option B: Terminal command
cd server && npm install && npm start
2

Register with Your AI Coding Agent

Choose your coding assistant below to get the exact setup command:

Run this command in your terminal to register the tool globally:

claude mcp add developer-companion node server/server.js

Or provide the absolute path to server/server.js.

  1. Open Cursor Settings (Cmd+, or Ctrl+,).
  2. Navigate to Features > MCP > + Add New MCP Server.
  3. Enter the following values:
Name: developer-companion
Type: command
Command: node /absolute/path/to/server/server.js

Add this entry to your MCP configuration file (mcp.json):

{
  "mcpServers": {
    "developer-companion": {
      "command": "node",
      "args": ["/absolute/path/to/server/server.js"]
    }
  }
}

In Cline, Roo Code, or any VS Code MCP extension:

  1. Open MCP Settings.
  2. Add a new stdio server named developer-companion.
  3. Set command to node and args to ["/absolute/path/to/server/server.js"].
3

Start Using It With Prompts

Your agent now has these tools built in. Try asking:

Generate UI Code "Check get_latest_sketch and write the HTML/CSS component."
Fix Browser Errors "Read the browser logs from localhost with get_browser_logs and fix the exception."
Manage Repositories "List my GitHub repos using get_github_repos."
